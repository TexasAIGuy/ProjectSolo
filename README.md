# iTunes Music Search

A small interactive front-end web app that lets you search the iTunes catalog for songs, albums, and music videos. It uses the free iTunes Search API and is built with plain HTML, CSS, and JavaScript.

## Features

- Search by artist, song title, or album
- Choose between songs, albums, or music videos
- Displays artwork, artist, album, and release year
- Optional audio previews for songs and music videos
- Responsive layout that works on mobile and desktop

## Technologies Used

- HTML5 (semantic elements like `header`, `main`, `section`, `button`)
- CSS3 (custom styling + responsive layout)
- Vanilla JavaScript (DOM manipulation, `fetch`, async/await)
- iTunes Search API
